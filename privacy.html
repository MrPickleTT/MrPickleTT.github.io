Jarvis Privacy Policy

Last updated: November 2, 2026

Who uses Jarvis

Jarvis is a personal assistant built and used only by Trent Heller. It has no other users and is not available to the public.

What data Jarvis accesses

With the account owner's explicit permission, Jarvis requests read-only access to:

  • Gmail (read-only): to search and read the owner's own email when asked.
  • Google Calendar (read-only): to list the owner's upcoming events.
  • Google Drive (read-only): to search and read the owner's own files when asked.

Jarvis cannot send, delete, edit, or share any email, event, or file.

How data is used and stored

  • Data is used only to answer the owner's own requests (for example, summarizing upcoming events or finding an email).
  • Data is processed on the owner's personal computer. Access tokens are stored locally on that computer and are readable only by the owner's account.
  • Data is never sold, shared with third parties, used for advertising, or used to train AI models.

Google API Services User Data Policy

Jarvis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from Google Account → Security → Third-party apps & services. Revoking access immediately stops Jarvis from reading Gmail, Calendar, or Drive.
